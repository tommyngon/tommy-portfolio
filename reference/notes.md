# Bulbs — Animation & Interaction Reference

## 1. The website feels alive without constantly moving

The biggest thing I like is that the site doesn't try to prove that it is interactive. There isn't animation everywhere just for the sake of animation. The page feels quiet, strange and slightly organic, which fits the objects themselves.

The interaction should feel like you're handling something physical, rather than operating a piece of software.

The animations are restrained enough that the photography remains the main event. Nothing should compete with the objects.

## 2. The images should feel like objects sitting in space

The photography is treated almost like physical objects in an exhibition rather than ordinary website cards.

I like the feeling that the images have their own presence and aren't simply thumbnails inside a rigid grid.

The important reference here is:

> "The objects feel placed onto the website rather than rendered inside a website."

There is a nice tension between a very minimal interface and photographs of highly organic, irregular objects.

For our implementation, images should have enough freedom to feel slightly independent from the surrounding layout.

## 3. Scrolling is the primary interaction

The experience is fundamentally driven by scrolling through the collection.

The user doesn't need to constantly click buttons to progress. You move through the work naturally, and the website reveals the collection progressively.

This makes the interaction feel closer to walking through an exhibition than browsing an e-commerce catalogue.

The scroll should therefore feel smooth and intentional rather than mechanically snapping between sections.

## 4. Keep the motion slow, smooth and slightly delayed

The movement should have inertia.

Elements shouldn't immediately stop the exact moment the user's input stops. There should be a subtle sense of momentum, as though the interface has some physical weight.

The reference feeling is:

> "I move the page, and the website follows me rather than simply jumping where I told it to go."

Avoid aggressive easing, elastic UI animations or exaggerated spring physics.

The motion should feel expensive because it is controlled, not because it is flashy.

## 5. Typography should participate in the movement

The typography is extremely minimal, so even small movements become noticeable.

Text shouldn't simply appear as static HTML sitting above the images. It should feel connected to the movement of the page.

The collection names and navigation elements should remain extremely clean and restrained.

The site demonstrates that small typographic movements can have more impact than large decorative animations when the rest of the interface is quiet.

## 6. Navigation feels deliberately lightweight

The navigation is extremely simple:

- Collection
- About
- Contact
- Price List

There is no heavy navigation bar trying to explain everything. That simplicity is important.

The interaction should feel almost instantaneous: clicking a navigation item should produce a transition rather than feeling like a traditional page reload.

The interface gives the impression that the content is always nearby.

## 7. The Contact interaction is a good example of "hidden until needed"

The contact form isn't permanently occupying space on the page. Instead, "Contact" behaves like an invitation to open another layer of the experience.

The form itself is minimal:

- Name
- Email
- Message
- Send
- Close

This creates a useful interaction principle:

> "Don't show the interface until I ask for it."

For our own site, secondary information should behave similarly. Things that aren't part of the main visual experience can live behind small interactions rather than permanently taking up visual space.

## 8. The transition between collection and information should feel like a change of state

The About page contains considerably more text than the collection, but the visual language stays extremely stripped back.

This is useful because it shows that the site can move from:

**visual / atmospheric → informational**

without suddenly becoming a completely different website.

The transition should preserve the same spatial logic, typography and restraint.

## 9. The interface should never feel "UI-designed"

This is probably one of the most important references.

The website doesn't feel like someone designed a collection of standard components:

`navbar → hero → cards → buttons → footer`

Instead, it feels like an art-directed environment that happens to have navigation. That distinction matters.

The interaction should be invisible enough that the user notices the work first and the website second.

## 10. Hover interactions should feel like discovering something

When an interactive object is hovered, the response should be subtle and immediate.

The goal isn't:

> "HERE IS A HOVER ANIMATION."

The goal is:

> "Oh, this is interactive."

Small changes in position, scale, opacity or cursor behavior are enough.

The user should discover interaction rather than being instructed how to use it.

## 11. There is a nice contrast between rigid typography and organic imagery

This is one of the strongest aesthetic principles of the site.

The photographs show irregular, biological, almost alien forms. The typography and interface are extremely controlled. That contrast makes the objects feel even more unusual.

For our own implementation:

**organic content + precise interface = strong contrast**

Don't make every animation organic just because the imagery is organic. The restraint of the interface is what makes the organic imagery work.

## 12. Avoid conventional card animations

I would specifically avoid:

- cards popping upward on scroll
- excessive fade-ins
- huge scale animations
- bouncing elements
- generic parallax
- text flying in from every direction
- exaggerated cursor effects
- excessive blur transitions

Those would immediately make the experience feel like a modern portfolio template.

The Bulbs reference works because it has less animation than you'd initially expect.

## 13. The site should feel slightly mysterious

There is an element of discovery in the way the collection is presented.

You don't immediately get a giant explanation of what everything is. You encounter the objects first. Then you discover names, information and context.

That suggests an interaction hierarchy:

**see → explore → discover → understand**

rather than:

**read → click → navigate → see**

This is a very useful principle for an art/design-oriented website.

## 14. Movement should reinforce the physicality of the work

The objects themselves are described as hybrid lamps conceived almost as living organisms, and the project explicitly plays with the relationship between craft, nature and technology.

The website's interaction therefore benefits from feeling material rather than purely digital.

Good animation references:

- slight inertia
- soft easing
- gradual reveals
- movement with weight
- images that feel like physical things
- transitions that feel spatial
- subtle changes rather than abrupt state changes

Bad references:

- mechanical UI transitions
- overly precise snapping
- game-like effects
- flashy particle systems
- excessive motion

## 15. The overall animation philosophy

The best way I would describe the animation language is:

**Quiet, physical, spatial and slightly strange.**

Nothing should scream for attention.

The interface should feel like it has a physical relationship with the content.

The animations should make the website feel alive, but not obviously "animated."

The ideal reaction is:

> "Why does this feel so nice to scroll through?"

rather than:

> "That animation was cool."

---

## Priority Order

If we only reproduce a few things, prioritize them in this order:

1. **Physical scrolling** — Smooth, weighted scrolling with subtle inertia.
2. **Image presence** — Treat images as objects with their own spatial identity rather than generic cards.
3. **Minimal transitions** — Page/state changes should feel smooth and spatial rather than like hard navigations.
4. **Extremely restrained UI** — Keep navigation and controls almost invisible until they are needed.
5. **Typography movement** — Use subtle movement in text and labels rather than large animated typography.
6. **Discovery-based interaction** — Hover and click states should reveal interactivity rather than advertise it.
7. **Organic vs. precise contrast** — Let the content be weird and organic while the interface remains extremely controlled.
8. **No gratuitous effects** — Every animation should have a reason to exist.

## One-sentence design rule

**Make the website feel like a quiet physical space containing strange objects, not like a webpage containing animated objects.**
